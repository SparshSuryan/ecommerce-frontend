# E-Commerce Frontend
A responsive e-commerce frontend developed during my internship.  
The project focuses on creating a smooth shopping interface with product browsing, cart management, and user authentication.

## Features
- Responsive e-commerce UI
- Product listing and product detail pages
- Shopping cart functionality
- Checkout interface
- User authentication using Firebase
- Contact and About pages
- Optimized JavaScript files for improved performance

## Tech Stack
- HTML5
- CSS3
- JavaScript
- Firebase Authentication

## Pages
- **Home Page** – Includes the hero section and a button to the products page
- **Product Page** – Shows product details
- **Cart Page** – Manages items added to cart
- **Checkout Page** – Order summary and checkout flow
- **Auth Page** – User login/signup using Firebase
- **About Page** – Information about the platform
- **Contact Page** – User contact form

## My Role
During my internship, I contributed to building the frontend of the e-commerce platform. My work included implementing responsive layouts, developing product and cart functionality, integrating Firebase authentication, and optimizing JavaScript files for better performance.

## How to Run
1. Clone the repository
2. Navigate to the project folder
3. Open `index.html` or other pages in your browser
